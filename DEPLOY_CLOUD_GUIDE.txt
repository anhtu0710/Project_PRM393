- Giảng viên test APK trên điện thoại 24/7 mượt mà từ bất kỳ đâu (4G, Wi-Fi nhà).

--------------------------------------------------------------------------------
BƯỚC 1: CÁC THÔNG SỐ CẦN LẤY TỪ AIVEN.IO
--------------------------------------------------------------------------------
1. Truy cập trang Aiven của bạn (Service pg-26494055 đang Running).
2. Cuộn xuống khung "Connection Information", lấy 4 thông số:
   - Host:     pg-26494055-xxxx.aivencloud.com
   - Port:     25432 (hoặc số port Aiven cấp)
   - User:     avnadmin (hoặc defaultuser)
   - Password: (Mật khẩu tự động Aiven cấp)
   - Service URI: postgres://avnadmin:password@host:port/defaultdb?sslmode=require

--------------------------------------------------------------------------------
BƯỚC 2: CHẠY SCRIPT SQL KHỞI TẠO BẢNG & DỮ LIỆU
--------------------------------------------------------------------------------
1. Ngay trên giao diện Aiven ➔ Mở tab "Quick Connect" / "Query Editor" (hoặc kết nối DBeaver / pgAdmin bằng Service URI ở Bước 1).
2. Mở file GỘP DUY NHẤT: `combined_database_setup_postgres.sql` trong dự án.
3. Copy toàn bộ nội dung file ➔ Dán vào Query Editor trên Aiven ➔ Bấm "Run / Execute".
4. Kiểm tra các bảng User, Hotel, Room, Booking, PriceConfig, Voucher đã được tạo kèm dữ liệu mẫu.

--------------------------------------------------------------------------------
BƯỚC 3: CẤU HÌNH BIẾN MÔI TRƯỜNG TRÊN RENDER.COM
--------------------------------------------------------------------------------
1. Đảm bảo thư mục `backend` đã được Push lên GitHub.
2. Truy cập https://render.com ➔ Tạo "Web Service" chọn Repository `backend`.
3. Điền thông số Build:
   - Build Command: ./mvnw clean package -DskipTests
   - Start Command: java -jar target/PRM393GenZ-0.0.1-SNAPSHOT.jar
4. Vào mục "Environment Variables" trên Render ➔ Bấm "Add Environment Variable" điền 3 dòng:

   Biến 1:
   Key:   SPRING_DATASOURCE_URL
   Value: jdbc:postgresql://<AIVEN_HOST>:<PORT>/defaultdb?sslmode=require
   (Ví dụ: jdbc:postgresql://pg-26494055-xxxx.aivencloud.com:25432/defaultdb?sslmode=require)

   Biến 2:
   Key:   SPRING_DATASOURCE_USERNAME
   Value: <AIVEN_USER> (Ví dụ: avnadmin)

   Biến 3:
   Key:   SPRING_DATASOURCE_PASSWORD
   Value: <AIVEN_PASSWORD> (Mật khẩu trên Aiven)

5. Bấm "Create Web Service". Render tự động build và cấp URL:
   https://genzcinema-backend.onrender.com/api

--------------------------------------------------------------------------------
BƯỚC 4: BUILD APK CHO GIẢNG VIÊN TEST
--------------------------------------------------------------------------------
1. Mở Terminal tại thư mục `mobile` chạy lệnh:
   cd mobile
   flutter build apk --release --dart-define=API_URL=https://genzcinema-backend.onrender.com/api

2. File APK xuất ra tại:
   D:\RioSpace\FPT\PRM\Project_PRM393\mobile\build\app\outputs\flutter-apk\app-release.apk

3. ĐỔI SERVER TRỰC TIẾP TRÊN APP KHI CẦN (KHÔNG CẦN BUILD LẠI APK):
   - Mở App trên điện thoại ➔ Màn hình Đăng nhập ➔ Nhấn nút "⚙️ Cấu hình Server API".
   - Dán URL bất kỳ (Wi-Fi IP, Ngrok hoặc Cloud URL) ➔ Bấm "Lưu & Kết nối".
